# AI-Generated Solutions to Generalized Min-Cost Flow

This repository collects **mostly AI-generated** solution drafts for the generalized minimum-cost flow problem (generalized flow where every arc gain satisfies 0 < γₑ). Each draft aims at an almost-linear-time algorithm, and each takes a somewhat different route.

**Authors / maintainers:** Gernot Zöcklein, Rasmus Kyng, Maximilian Probst-Gutenberg

> **Note:** **These are mostly unverified, machine-generated mathematical write-ups.** Please read the [Verification status](#verification-status) section before relying on any claim in them.

Every solution folder contains the LaTeX source and a compiled PDF. To rebuild a PDF, run `latexmk -pdf <file>.tex` inside its folder.

## Verification status

- **Overall: not yet fully digested.** We have skimmed all outputs and cross-checked them with other models. No draft has been fully verified.
- **`generalized-min-cost-flow.tex`** is **currently being verified** and looks good so far, and is the version we are most interested in: claims reduction to O(log^4 n) calls to ordinary MCF.

## How the solutions were generated

- **`lossy_flow_unconditional_draft.tex`**: generated in a conversation with **GPT 6 Astra** in October 2026.
- **`generalized-min-cost-flow.tex`**: generated by talking to ChatGPT and trying to combine the best ideas from all the other drafts.
- **`6.2-Astra_hint_solution1.tex`**: generated by [**TCS-Prover**](https://github.com/yonggangjiang/tcs-prover) (by Yonggang Jiang) running **GPT 6.2 Astra**.
- **`6.2-sol_nohint_solution.tex`**: also generated by [**TCS-Prover**](https://github.com/yonggangjiang/tcs-prover), this time running **GPT 6.2 Sol**.
